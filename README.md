# neovim-config (archived)

**This repo is archived.** Since 2026-10-26 my editor is
[Yeyito777/neovim](https://github.com/Yeyito777/neovim): a Neovim fork with
this config built into it, no dotfiles and no plugin manager. See its
[YEYITO.md](https://github.com/Yeyito777/neovim/blob/yeyito/YEYITO.md).

This is the plugin-based `~/.config/nvim` (lazy.nvim) it replaced, kept for
history. The last two commits are the final config on each machine, which had
drifted apart:

- `Final whale config`: whale (Linux)
- `Final Mac config`: the MacBook; the newer superset the fork was built from

`lazy-lock.json` pins the plugins as they were last used. `NATIVE_WRAP.md` and
`MARKDOWN_LINKS.md` describe the setup at the time; the paths in them
(`~/.local/opt/neovim-visible-wrap`, `~/.config/nvim`) no longer exist on either
machine.

What became of each plugin is listed in the fork's YEYITO.md.
